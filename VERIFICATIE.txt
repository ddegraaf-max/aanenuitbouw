Wijziging 1 — broncode niet meer uitleveren
-------------------------------------------
serveStatic serveerde alles onder ROOT. Daardoor was /server.js publiek
leesbaar, en straks ook /src/sondeertool/. Nu geblokkeerd:

  /server.js                                    -> 404
  /package.json                                 -> 404
  /src/sondeertool/index.js                     -> 404
  /.env                                         -> 404
  /bodemcheck/assets/../../../server.js         -> 404

Geen sleutels gelekt (die staan in Railway-variabelen), maar het gaf een
aanvaller wel het bouwplan van je adminlogin.

Wijziging 2 — rate limiting op adminpogingen
--------------------------------------------
/api/auth/check had geen limiet en geen vertraging: een schone 200 bij goed,
401 bij fout. Daarmee was ADMIN_PASSWORD ongelimiteerd te raden. Nu:

  10 mislukte pogingen per IP per 15 minuten, daarna 429
  300 ms vertraging bij elke mislukte poging
  ALLEEN mislukte pogingen tellen mee -- een geslaagde login wist de teller

Gemeten:
  poging  1-10  -> 401 {"ok":false}
  poging 11-13  -> 429 Te veel mislukte inlogpogingen
  juist wachtwoord terwijl IP geblokkeerd -> 429 (dus geen ontsnapping)
  POST /api/prices, /api/planning, /api/projects met fout wachtwoord -> 429

Tegenproef, want een limiet die jou buitensluit is nutteloos:
  inloggen                          -> 200 {"ok":true}
  20x achter elkaar prijzen opslaan -> 20x 200, geen enkele 429
  9 fouten, dan juist wachtwoord    -> 200, teller gereset
  daarna weer 9 fouten + juist      -> 200, dus de reset werkt echt
  planning opslaan                  -> 200
  project aanmaken                  -> 200, code AEB-XXXXX
  publieke code-check               -> 200 met het juiste label

Ook opgelost: /api/auth/check riep checkAuth twee keer aan.

Wijziging 3 — sondeertool-hook
------------------------------
Eén regel vóór serveStatic, onderaan de request-handler:

  if (await require('./src/sondeertool').handle(req, res, url)) return;

handle() geeft false terug voor elk verzoek buiten /bodemcheck, dus serveStatic
loopt dan gewoon door. Gemeten na de wijziging:

  /                    -> 200 configurator
  /project             -> 200 project
  /configurator.html   -> 200
  /api/health          -> 200
  /api/prices          -> 404 (No prices set yet, zoals verwacht)
  /nietbestaand        -> 404 Niet gevonden (jouw eigen tekst)
  /bodemcheck                            -> 200 de bodemcheck-pagina
  /bodemcheck/assets/sondeertool.css     -> 200
  /bodemcheck/api/analyse?lat=..&lon=..  -> 200

Geen nieuwe dependencies. package.json is niet aangeraakt.
